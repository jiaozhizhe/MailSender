# MailSender · 邮件分发助手（免安装版）

**这个文件夹里的版本不需要任何环境，下载后双击就能用。**

## 怎么用

1. 下载本文件夹里的 `FileSender.exe`（36MB 左右，单文件即全部）
2. 在你的电脑上新建一个文件夹（比如 `D:\邮件分发助手`），把 exe 放进去
3. 双击运行——**不需要安装 Python，不需要安装任何东西**

⚠️ 被 Windows SmartScreen / 杀毒软件拦一下属正常（无签名的个人开发者程序都这样）：点「仍要运行」或加入信任白名单即可；不放心可用 `FileSender.exe --selftest` 自检（25 项全过即完整）。

## 首次使用

1. 「② 收件规则」：录入 关键字 / 收件人姓名 / 邮箱（支持 Excel 批量导入）
2. 「③ 邮箱设置」：SMTP 服务器 + 账号 + 密码（多数邮箱须用授权码/客户端专用密码，说明见程序内提示），点「测试连接」验证
3. 「① 发送」：添加文件夹 → 扫描并匹配 → 开始发送

完整说明：见本仓库 `FileSender-Python/使用说明.html`（浏览器直接打开）。

## 常见问题

**Q: 为啥我双击没反应 / 被拦截？**
A: 杀毒软件误报，加白名单或点仍要运行。程序打包自开源源码 `file_sender-python.py`，可用 `FileSender.exe --selftest` 自检验证完整性（25 项全过即正常）。

**Q: 杀软报毒不放心怎么办？**
A: 可以不用 exe：到本仓库 `FileSender-Python/` 文件夹拿源码自己打包（README 里有两条命令），或让会 Python 的同事帮忙打包，同样几条命令的事。

**Q: 换电脑能用吗？**
A: 能。把 exe 和它旁边的 `config.json`（有配置后自动生成）一起拷走即可；记住的密码存在原电脑凭据管理器里，新电脑重新输一次。

**Q: 会不会动我的文件？**
A: 不会。程序只读文件作为附件发送，不移动、不重命名、不修改、不删除任何原文件；每轮发送生成「发送清单」Excel 备查。
