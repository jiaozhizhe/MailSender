# MailSender · 邮件分发助手

按「文件名关键字」自动把文件分发给对应收件人的邮件工具——文件多、收件人多、发错就麻烦的批量报送场景而设计（报告单、报表、通知函…）。

例如规则设「临江大学紫金 → 张三」，那么「临江大学紫金2608.xlsx」「临江大学紫金2609.xlsx」都会自动合并成一封邮件发给张三。

## 核心特性

- **最长关键字优先**：同时配「临江大学」与「临江大学紫金」时命中更长者；零命中或等长命中多人自动停发待确认，绝不乱猜乱发
- **合并发送**：同一收件人多个文件合并一封邮件（可切逐文件）
- **发送前确认**：先弹收件清单过目，确认后才发出
- **全程留痕**：每轮发送自动生成「发送清单」Excel（xlsx，缺依赖自动降级 csv），谁收到什么、哪些没发、失败原因全部可查
- **失败重发**：只补发失败项；被占用/丢失的附件单独进待补发池，解锁后一键补发
- **SMTP 会话复用**：一轮发送只登录一次，断线自动重连，连续连接失败自动熔断（防企业邮箱风控）
- **密码保管**：Windows 凭据管理器，不可用时经用户确认后回退明文
- **安全底线**：只读文件绝不改动原件、附件超限预检拦截、危险后缀（exe/bat 等）自动跳过、Excel 公式注入防护、密送不进邮件头
