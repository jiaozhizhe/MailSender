邮件分发助手 · 使用说明

按文件名关键字自动把文件分发给对应收件人的邮件工具
双击即用 · 无需安装任何环境 · 只读文件绝不改动原件

开源工具 · 欢迎反馈与改进

开始前先看这一句：把「邮件分发助手.exe」拷到任意文件夹，双击即可运行。首次使用按「②收件规则 → ③邮箱设置」的顺序配置一次，之后日常只做「①扫描→发送」两步。

一、它帮你做什么

你指定若干文件夹，程序扫描里面的文件；只要文件名里包含某个关键字，就自动发给该关键字对应的收件人。同一收件人的多个文件默认合并成一封邮件（附件打包）。例如规则里设「临江大学紫金 → 张三」，那么「临江大学紫金2608」「临江大学紫金2609」都会发给张三。

五条安全底线（已内置，无需设置）

  • 只读不改：文件只作为附件读取发送，不移动、不重命名、不删除、不修改原件
  • 发不出去就不硬发：文件名匹配不到关键字、或同时匹配到多个不同收件人时，该文件自动停发并列出，绝不乱猜乱发
  • 附件超限自动拦截：单封邮件附件合计超过上限（默认 45MB）直接不发送并记录原因，避免被邮件服务器退信；上限可在「③邮箱设置」页调整
  • 每封发送前都有确认：点「开始发送」会先弹出收件清单让你过目，确认后才真正发出
  • 全程留痕：每次发送（含重发）自动生成「发送清单」Excel，谁收到了什么、哪些没发、失败原因，全部可查可核验

二、三步上手

  1. 第一步：设置收件规则（② 收件规则页）

    点「新增」，填三样：关键字（如"临江大学紫金"）、收件人姓名、邮箱。人多的可以按「A列=关键字、B列=姓名、C列=邮箱」做成 Excel 用「从Excel导入」一次灌入。录完点「保存规则」。

  2. 第二步：设置发件邮箱（③ 邮箱设置页）

    填 SMTP 服务器、端口、加密方式、账号、密码/授权码，点「保存设置」，再点「测试连接」验证能通。拿不准参数时见第四节。

  3. 第三步：扫描并发送（① 发送页）

    「添加文件夹」选中要分发的文件所在目录 → 点「扫描并匹配」 → 核对表格里每个文件的收件人 → 点「开始发送」→ 在确认弹窗里过目收件清单 → 确认。发送完自动弹出「发送清单」文件夹。

三、匹配规则（关键）

3.1 长关键字优先

文件名同时含多个关键字时，最长的关键字说了算。所以可以放心同时配「临江大学」和「临江大学紫金」：前者只接兜底的活。

已配关键字文件名命中结果发给谁
临江大学紫金临江大学紫金2608.xlsx命中「临江大学紫金」（5字，最长）命中该关键字对应的收件人
临江大学临江大学2607.docx只命中「临江大学」命中该关键字对应的收件人
两个都没配随意一个文件.txt未匹配自动停发，列入待处理清单

3.2 冲突与未匹配：不猜、不硬发

两类文件会被自动停发：一是未匹配（不含任何关键字）；二是冲突（文件名里两个等长的关键字指向不同的人，比如「项目决算」和「决算清单」都指向不同人）。这些文件会在表格里灰色/红色标出、不发送。处理方式：

  • 选中该行 → 双击或点「手动指定收件人」：从已有规则里选，或直接填一个邮箱，即可纳入本轮发送；
  • 或点「未匹配/冲突文件另存副本」，把这些文件复制到一个文件夹集中处理（只复制，不动原件）。

3.3 合并发送与拆分发送

默认「同一收件人的多个文件合并为一封」收件人只收一封、附件打包。取消勾选则每个文件一封。另外「包含子文件夹」勾上后会把子目录里的文件也扫进来。

自动排除项：WPS/Office 打开文件时产生的「~$」开头锁文件、未下载完成的临时文件，都会被自动跳过，不会被当成附件发出去。此外，exe、bat、cmd、ps1、js、vbs、scr 等可执行/脚本文件也会被自动跳过，防止误发危险文件——如确需发送此类文件，请先压缩打包并改名。

四、邮箱设置与参数速查

这套设置一次填好、长期保存。公司内部邮箱的参数请向 IT 确认，或看公司邮箱的「设置/帮助」页。

加密方式常用端口适用情况
SSL465最常见的加密方式，互联网邮箱（QQ/163/腾讯企业邮）多用这个
STARTTLS587 或 25先明文连接再升级加密，部分企业服务器采用
none（不加密）25纯内网邮件中继。此时取消勾选「登录认证」，但必须填写「发件邮箱地址」。⚠ 尽量避免：25 端口为明文传输，账号密码与附件可能被同网段截获，内网若支持 SSL/STARTTLS 请优先使用（程序选中此项时也会弹出黄字提醒）
  • 证书校验（三档，默认不校验）：①不校验——默认，内网自签名/内部 CA 证书直接能用；②校验证书链——验证服务器证书由信任的 CA 签发但不校验主机名，适合内网 CA（用 IP/别名连也不断），若 IT 提供了内部 CA 的 pem 文件可填在「CA证书文件」里；③严格校验——证书链+主机名全验，适合公网邮箱（QQ/163 等）；
  • 附件单封上限（MB）：默认 45，按邮件实际大小计（附件 base64 编码后约膨胀 1.37 倍，网关拒收也按这个口径），超限直接拦截不发送并写明原因，调大上限后可点「重发失败项」补发；
  • 抄送/密送：均在设置页填写，分号分隔。密送收件人不会出现在邮件里（对方看不到彼此）；
  • 密码/授权码：很多企业或互联网邮箱不收登录密码，而要用「授权码/客户端专用密码」，在公司邮箱「设置→客户端发信」里生成；详细步骤看下方说明；
  • 记住密码：勾选后密码保存在本机 Windows 凭据管理器（加密、不随 config.json 走），公用电脑勿勾；个别环境凭据管理器不可用时程序会自动退回 config.json 明文保存并在界面提示；换电脑需重输一次密码；
  • 发件邮箱地址：多数情况留空即可（=发件账号）；仅当你用域账号登录内部中继、而发件地址与账号不同时才需要填；
  • 主题/正文模板：支持占位符——{姓名} {关键字} {文件数} {文件名}，按需改写；手动指定的收件人未提供姓名时，{姓名} 自动用邮箱前缀；{邮件数}/{附件数} 与 {文件数} 含义相同（均指该封邮件实际发送的附件份数），保留是兼容旧模板，建议统一用 {文件数}；
  • 每封间隔：默认 1 秒，批量较大时可调大，降低被服务器限流的概率。

客户端专用密码 / 授权码（多数企业邮箱与个人邮箱必看）

很多企业邮箱的网页登录密码和客户端发信密码不是同一个：第三方邮件客户端（Foxmail、Outlook、本工具等）必须用「客户端专用密码 / 授权码」，直接填网页密码会报「邮件服务器返回错误 / 账号或密码不正确」。获取方式以你所在公司的邮箱说明为准，通常路径是：

  • ① 登录邮箱网页版（不要用客户端）；
  • ② 进入「设置」→「密码管理」或「账户安全」（各家邮箱叫法略有差异）；
  • ③ 找到「客户端专用密码」「授权码」「应用密码」之类的入口，生成一个；
  • ④ 弹出的密码通常只显示一次，立即复制保存；忘了就重新生成一个新的；
  • ⑤ 回到本工具「③ 邮箱设置」：密码栏粘贴该密码，勾「记住密码」（存入本机凭据管理器，下次不用再输）；
  • ⑥ 点「测试连接」出绿灯 → 点「发一封测试邮件」发给自己收一下，确认链路全通。

说明：每个客户端各生成一个专用密码、互不影响；管理页可查看每个客户端的添加/最近使用时间，不需要时随时停用。个人邮箱（QQ/163 等）的授权码在「设置 → POP3/IMAP/SMTP 服务」里生成。

建议的验证顺序（小额测试原则）：① 点「测试连接」确认能登录 → ② 「发一封测试邮件」发到自己的邮箱确认能收到 → ③ 建一个临时文件夹放几个测试文件、把规则指向自己的邮箱，完整跑一遍扫描→发送流程 → ④ 正式使用。

五、常见问题

Q: 双击后被杀毒软件拦截？

A: 程序是打包的单一 exe，部分杀软对这类文件会误报。请在杀软里将其加入信任/白名单即可；不会用的同学可以让 IT 协助放行。

Q: 提示发送失败怎么办？

A: 程序会给出能看懂的原因提示（括号里附技术详情）：密码/授权码不对、服务器地址或端口不对、连接超时、附件超过「单封上限」（到「③邮箱设置」调大后重发）、证书校验失败（内网自签证书把「证书校验」设为不校验）等。改好后点「重发失败项」，只补发失败的那几封；补发结果会完整写入新的发送清单。界面日志同时会自动保存到程序目录的 logs/ 文件夹（按天一个文件），退出程序不丢，事后可查。

Q: 发送过程中直接点右上角 × 关窗会怎样？

A: 不会静默丢信。程序会弹窗让你选：停止发送并保存进度后退出（已发出的邮件照常写入发送清单）、或等本轮发送完再退出；只有发送不在进行时才直接关。直接拔电源等极端情况无法防护，重要批次建议等清单生成后再关机。

Q: 发错了/发重了怎么办？

A: 每次发送后自动生成的「发送清单_日期.xlsx」里有每个文件的去向与发送时间（含未发送、失败原因），可先照单核实范围；程序本身不撤回邮件，需人工沟通说明。所以正式发送前务必利用确认弹窗过目收件清单。

Q: 配置存在哪？换电脑要重设吗？

A: 全部配置（规则、文件夹、邮箱设置）保存在 exe 同目录的 config.json。换电脑时把「exe + config.json」一起拷走即可；勾了「记住密码」的，密码存在本机 Windows 凭据管理器、不随文件走，换电脑后重输一次即可。

Q: 想检查这台电脑上程序是否一切正常？

A: 在 exe 所在文件夹打开 PowerShell（文件夹空白处 Shift+右键），运行「.\邮件分发助手.exe --selftest」，会在同目录生成 selftest_report.txt 自检报告（16 项全 OK 即正常，含界面、匹配、清单、附件拦截、证书三档、密码保管等检查）。

Q: 附件文件正被别人打开占用，发不出去怎么办？

A: 点「开始发送」时程序会预先检查每个文件能否读取：读不了的文件会在确认弹窗里明确列出并从邮件中剔除，其余文件照常发送，不会因为一个文件卡住整封邮件。被剔除的文件会进入待补发清单，关闭占用它的程序后点「重发失败项」即可补发。发送清单里也会记录每个文件的去向与具体原因。

Q: 中文文件名、特殊符号文件能发吗？

A: 能。附件名按国际编码标准封装，主流邮箱客户端（含 Foxmail、Web 邮箱、手机端）均正常显示中文附件名。个别以 =、+ 等符号开头的文件名，发送清单里会加一个「'」前缀防止 Excel 误当公式，属正常防护。
